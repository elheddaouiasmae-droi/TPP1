# 🐘 Cahier d'Exercices Pratiques
### Développement Backend (PHP) — Module M205

*Maîtriser les fondamentaux de PHP avant de se lancer dans Laravel.*

---

## 📖 À propos

Ce projet contient une série de **5 travaux pratiques (TP)** conçus pour maîtriser les fondamentaux de PHP avant de se lancer dans le framework **Laravel**.

L'objectif est de construire une base solide pas à pas :

- 🔹 Les **fonctions**
- 🔹 Les **tableaux** (indexés et associatifs)
- 🔹 La **programmation orientée objet (POO)**
- 🔹 L'**héritage** et le **polymorphisme**

---

## 🛠️ Prérequis

- ✅ **PHP 8.0** ou supérieur installé sur votre machine
- ✅ Un **terminal** (ligne de commande)
- ✅ Un **éditeur de code** (VS Code, PhpStorm, etc.)

Vérifier la version de PHP :

```bash
php -v
```

## 🚀 Lancer le projet

**1. Cloner le dépôt**

```bash
git clone https://github.com/USERNAME/php-backend.git
cd php-backend
```

**2. Exécuter un exercice**

```bash
# Activité 1
php activite1-fonctions/test.php

# Exercice 2
php exercice2-tableaux-indexes/tableaux.php

# Exercice 3
php exercice3-tableaux-associatifs/associatifs.php

# Exercice 4
php exercice4-classes/test.php

# Exercice 5
php exercice5-heritage/index.php
```
